## Website giới thiệu

Trang `index.html` là portfolio tĩnh giới thiệu thông tin sinh viên và ba sản phẩm
học tập. Các asset được dùng bằng đường dẫn tương đối để hoạt động khi deploy
trên GitHub Pages:

- `Lab05_Ex1.2.pdf`: tài liệu PDF xem trực tiếp bằng `<object>`.
- `Lab05_Ex2.1.png`: infographic xem trực tiếp bằng `<img>`.
- Video YouTube `RZuY-I2eNVU`: xem trực tiếp bằng `<iframe>`.

### Chạy thử

Mở `index.html` trực tiếp trong trình duyệt, hoặc chạy một static server tại thư
mục repo, ví dụ `python -m http.server 8000`, rồi truy cập
`http://localhost:8000`.

### GitHub Pages

Trong repository, vào **Settings → Pages**, chọn **Deploy from a branch**, chọn
branch `main` và thư mục `/ (root)`, sau đó bấm **Save**. URL dự kiến là:
`https://nguyencongloc-hash.github.io/CT005_Lab05/`.
